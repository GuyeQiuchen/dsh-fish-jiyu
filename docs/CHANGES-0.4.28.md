# 0.4.28 — 报告口径统一

只改报告，不改投影、不改渲染。

## 问题

同一份报告里两处说法不同：

| 位置 | 11-27 00:46 那次写的 | 实际 |
|---|---|---|
| `summary.mid / far` | 42 / 39 | 真发出去的行数 |
| `blocks[].tier` | 41 / 40 | 计划给哪档 |

差的那一块，是**计划定成「关键词指针」、渲染时提不出词，退成「事实行」**。
数字都在，但一份报告两套账，看的人会以为丢了一块。

## 改法

`lib/linear.js` 的 `build()` 里，`tiers` 不再记 `tierOf()` 的计划值，
改记**落地的那一档**（进 midItems → 1；进 farItems → 2）。
`summary` 本来数的就是发出去的行，两处从同一个账本出。

## 验证

同一份真实会话（1070 块，target = 压前 35%）：

| 项 | 改前 | 改后 |
|---|---|---|
| summary mid/far | 与 blocks 可能错位 | 402 / 338 |
| blocks 实际 | 计划值 | **402 / 338** |

全量测试 139/139。
