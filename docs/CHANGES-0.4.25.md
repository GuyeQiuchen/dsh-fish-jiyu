# 0.4.25

## 修：plan 逼真了两件事

### 1. 指针价对齐渲染

提不出关键词的块，`build` 会留成**事实行**（不是指针），但规划一直按指针价算。
现在 `costOf` 的指针分支按同样规则走：没词且有事实内容 → 按事实行计价。

### 2. 相关提档要计价（主因）

`tierOf` 会把两类块升成事实行：动过工具的块、和当前话题重合 ≥2 词的块。
规划原来按指针价装它们，渲染时却花了事实行的钱。

942 块那次：规划算 207 块事实行，实际渲染 449 块——多出 242 块低价高配，
超预算 1.2%（69,662 vs 目标 68,812）。

改法：先按原价算一遍 keep，用它推出当前话题，把会被提档的块按事实行重新计价，
再算第二遍。两遍都是纯函数，确定性不变。
