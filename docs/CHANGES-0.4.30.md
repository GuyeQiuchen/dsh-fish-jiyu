# 0.4.30 — 修：整块消失且不补指针

代码审查抓到的一个 off-by-one，会真丢东西。

## 症状

预算把某一块整个裁掉、而下一块的首条 seq 恰好等于本块 `endSeq` 时，本块被误判成
「已覆盖」，落脚点指针不再补——**整块从上下文里消失，且没有任何线索指回它**。

复现（8 条一块、共两块 40–47 / 48–55、target 500）：

```
输出 seq: 48,49,…,55        ← 40-47 整块没了，也没有「原文按 seq 取回」
```

## 原因

| 位置 | 写法 |
|---|---|
| 分桶（`lib/linear.js:508`） | `seq >= startSeq && seq < endSeq`（开区间） |
| 覆盖判定（`lib/linear.js:687`） | `seq >= startSeq && seq <= endSeq`（闭区间） |

下一块首条 seq 等于本块 endSeq，闭区间把它算进本块，于是本块被认为「有落脚点」。

## 改法

覆盖判定改成开区间，和分桶一致。

## 验证

| 项 | 结果 |
|---|---|
| 新增 `test/coverage.test.mjs` | 2 条：复现场景 + 9 种预算下每块都有落脚点 |
| 全量测试 | **155/155** |
| 真实会话验收 | ALL PASS（0 未覆盖、取回率 298/308、零改写） |

`test/jiyu.test.mjs` 的落点检查同时从 ±2 松窗口收紧成 `[startSeq, endSeq)`——
原来那个松窗口正是这条 bug 藏了两周的原因。
