# 0.4.24

## 修：plan 引擎的预算没花完

`plan.js` 按 `factShare` 给事实行预留 20%，但事实行实际用不完那份（块少、行短），
剩下的预算既没还给原文、也没别的去处。0.4.23 那次 target 68,812、预算 65,371，
实际只花掉 58,155，空 7.2k。

修法：分档之后加一段「余钱还给原文」——从最新的事实块往回逐块升级为原文，
装不下就停。仍然连续、仍然确定。

## 实测（同一份真实会话，目标 277,715）

| 引擎 | tokens | 填充率 |
|---|---|---|
| time（旧二分） | 235,695 | 84.9% |
| plan（0.4.23） | — | 约 89% |
| **plan（0.4.24）** | **250,165** | **90.1%**（占预算 94.8%） |

余下的约 5% 是 `headroom` 预留，设计如此。
