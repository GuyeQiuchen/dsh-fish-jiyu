# 0.4.16（2026-11-25）

## 远段关键词「逐条装」

以前：`近段 + 中段 + 远段 + 索引` 超 target 就**整段丢远段**——超 20 字符和超 2 万一样归零。
实测那次 target 68,812、压完 64,504，箱子还空 4.3k，远段 15 条只要约 1.4k；只要再多几百 token 就全没了。

现在：远段按剩余空间**逐条装**，装不下就停（不跳着装，避免时间轴上留空洞）：

- 排序：`work × 10 + related`，硬信号（动过工具）当主序，沾边当次序，同分取更近的；
- 硬上限：最多吃 `target × farShare`（默认 15%），防止远块多时把近段吃穿；
- 门槛：剩余空间小于 `MIN_FAR_LINE` 就不装远段。设计稿写 60，实测我们这条行只有 35 字符上下，按 60 会永远装不进，取 20。

## 近段上限可配：0.95 → 0.85

二分那条线原来是写死的 `target × 0.95`：近段吃掉 95%，索引 + 中段 + 远段只剩约 3.4k token。
索引约 2.5k、中段约 1k、远段约 1.4k，合计已经超了——这次能全装下纯属运气。

现在默认 0.85，并可用 `nearShare` 配置。代价：近段少 3–5 轮原文。

## 新增配置

| 键 | 默认 | 说明 |
|---|---|---|
| `nearShare` | 0.85 | 近段占 target 的上限 |
| `farShare` | 0.15 | 远段占 target 的硬上限 |
