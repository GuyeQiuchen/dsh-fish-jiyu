# 1.2.0（2026-11-28）· engine / nearShare 弃用

二分删掉之后，这两个配置键已经没有对应的实现。留着「可配但无效」比报错更糟：
用户会以为自己调了参数。这一版把它们标成弃用：**接受、提示一次、不生效**。

## 改动

| 键 | 之前 | 现在 |
|---|---|---|
| `engine` | `plan` 生效；`time` 当别名 | 不再解析；配了就警告「已弃用，已忽略」 |
| `nearShare` | 二分专用；plan 下已无作用 | 不再解析；配了就警告「已弃用，已忽略」 |

- `resolveEngineMode` 整个删除；`resolveConfig` 不再返回 `engine` / `nearShare`；
- `index.js` 投影调用不再传这两个参数，报告里的 `engine` 固定为 `"plan"`；
- `DEFAULT_NEAR_SHARE` 导出删除（连同两个只传旧参数的对照脚本）；
- `lib/engine/CONTRACT.md` 写明两键已弃用。

## 为什么是「弃用」不是「删键」

直接删掉允许名单，升级时旧 profile 里残留的 `engine: time` / `nearShare: 0.9`
会让 `validateKeys` 直接抛错，整个压缩插件起不来。弃用是**接受但忽略 + 警告**，
既不拦旧配置，也不再骗人。
